# Portable work table design

A wooden work table for computer work and ironing, with two cabinets (drawer + locker) that comes apart into 5 pieces without tools.

**Open the page:** `index.html` (3D view with colour choices, video, pictures, sizes, cut list, hardware list and assembly steps, in Roman Urdu).

| File | What it is |
|---|---|
| `index.html` | Main page: 3D design and colours at the top, then everything else |
| `rang_chunein.html` | 3D colour page, full screen |
| `images/` | 22 pictures (all sides, inside, sizes, working and ironing) |
| `video/` | Full video (1 min) and take-apart video (27 s) |
| `table_3d_model.glb` | 3D model (opens in any glTF viewer) |

Main sizes: top 61" × 25 5/8" (155 × 65 cm), height 34" (86 cm), legroom 24" (61 cm), two cabinets 18" wide.
